# CS-305-Portfollio

For my project, my client was Artemis Financial, a financial institution handling sensitive client money and retirement plans that needed secure software to protect against external threats and comply with strict regulations like GLBA and PCI-DSS. During the assessment, I did a great job manually inspecting the codebase to uncover critical security flaws like hardcoded database credentials (`root/root`) and missing input sanitization. Coding securely is super important because it safeguards user privacy, maintains company trust, and prevents expensive data breaches. While sorting through all the OWASP dependency-check warnings was a bit challenging, running those tests was extremely helpful for identifying vulnerable third-party libraries and CVEs.

To increase layers of security, I externalized the database credentials, enforced HTTPS traffic, integrated authentication controls, and updated dependencies in the `pom.xml` file. In the future, I'd use automated security scanners and dependency checks to assess risks and pick mitigation strategies. I made sure the app remained functional and secure after refactoring by testing features and re-running checks to ensure no new vulnerabilities were introduced. The coding practices, Maven dependency tools, and mitigation strategies I learned will definitely be helpful in future tech tasks, and I'd proudly show this completed vulnerability assessment project to future employers to prove my cybersecurity and secure coding skills.
